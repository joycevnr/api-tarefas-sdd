# Missão

## Por que existe
API simples para registrar, listar e concluir tarefas, servindo de backend
para qualquer cliente (web, mobile, CLI).

## O que entrega (MVP)
- criar, listar, concluir e remover tarefas de um usuário;
- uma API REST estável e previsível.

## Critérios de sucesso
- um cliente faz o ciclo completo de uma tarefa sem ler o código-fonte;
- toda operação responde em menos de 300 ms no ambiente local.

## Fora do escopo (por enquanto)
- colaboração entre usuários, tags, lembretes, anexos.
